# FinalFrontiersExporter

A simple KSP plugin that exports the Final Frontiers Hall of Fame ribbons into an HTML file.

## How to use

While in the space centre, press `Ctrl + F8` and in theory it should work. <br>
The exported HTML file will be in your base KSP directory, for example: `C:\Program Files (x86)\Steam\steamapps\common\Kerbal Space Program\ribbons.html`

## Building it yourself

Clone the repo and then if needed, edit the KSP base directory property inside of the `Directory.Build.props` file to match your situation.
